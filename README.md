# Memory Game: Не тот и не этот

Мемори-игра в жанре овощного тёмного фэнтези.

В королевстве объявлен отбор женихов. Восемь принцев-овощей явились ко двору, и каждый уверен, что принцесса выберет именно его. Принцесса не спешит: она приглядывается, переворачивает карточки и ищет тех, кто ей не подходит. Не подошедших она съедает. Остаётся один, и это её избранник.

Ваша задача: помочь принцессе. Запоминайте, кто где сидит, и находите пары как можно быстрее. Чем меньше ходов, тем выше вы в таблице лучших вечеров.

**Демо:** <деплой>

## Правила

- Перед вами 16 карточек: 8 принцев, каждый в двух экземплярах. Все лежат рубашкой вверх.
- Ход: откройте две карточки. Это считается ходом, даже если вы промахнулись.
- Принцы совпали: принцесса отвергает его и съедает. Карточки остаются открытыми, а под полем появляется её вердикт.
- Принцы разные: карточки на секунду остаются открытыми, потом закрываются. Пока они не закрылись, другие выбрать нельзя. Запоминайте!
- Последняя найденная пара: принцесса делает выбор. Появляется окно с её избранником и вашим числом ходов.
- "Новый ужин" в любой момент раздаёт карточки заново. Незаконченная партия в рейтинг не попадает.
- "Лучшие вечера" показывают 10 лучших партий: сначала те, где меньше ходов, при равенстве выше более ранняя. Результаты хранятся в браузере и переживают перезагрузку.
- Окна закрываются кнопкой "Закрыть", кликом по затемнённому фону или клавишей Escape. Игра при этом не сбрасывается.

## Особенности

- Вся разметка создаётся из JavaScript через `document.createElement`. В `<body>` только `<script>`, никаких библиотек и фреймворков.
- Игру можно пройти с клавиатуры. Закрытые карточки не выдают скринридеру, кто за ними прячется. Ходы, пары и вердикт озвучиваются через live-регионы. Анимации отключаются, если в системе включено уменьшение движения.
- У каждого съеденного принца есть своя история и свой вердикт.
- Звуки, ползунок громкости и сохранение выбранной громкости.

## Технологии

HTML, CSS, JavaScript (ES-модули). Сборщиков и зависимостей нет.
Архитектура похожа на мини-Redux: единое состояние в `store`, чистый `reducer`, а звуки, таймер закрытия и окно победы подписаны на изменения как независимые эффекты.

## Структура проекта

```
app/
  core/       игровая логика: константы, reducer, селекторы, колода
  store/      хранилище состояния
  services/   localStorage: таблица лидеров, громкость
  effects/    реакции на изменения состояния: звуки, таймер, победа
  ui/         компоненты интерфейса
  utils/      вспомогательные функции
styles/       стили
assets/       изображения и звуки
```

## Локальный запуск

ES-модули не работают при открытии файла напрямую (`file://`), нужен локальный сервер.

```bash
git clone https://github.com/YaroslavaGD/memory-game.git
cd memory-game
git checkout memory-game
npx serve
```

Откройте адрес, который покажет команда (обычно `http://localhost:3000`). Альтернатива: расширение Live Server в VS Code, команда «Open with Live Server» на `index.html`.
